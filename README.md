# NIROB'S AI

এটা একটা স্বাধীন AI চ্যাট ওয়েবঅ্যাপ — নিজের সার্ভারে চলবে, claude.ai-এর দরকার হবে না। এটা **ফ্রি** Google Gemini API ব্যবহার করে — কোনো কার্ড লাগে না।

## যা যা লাগবে
1. একটা ফ্রি Gemini API key — https://aistudio.google.com/apikey এ গিয়ে Google অ্যাকাউন্ট দিয়ে লগইন করে "Create API key" চাপুন (কোনো কার্ড/টাকা লাগবে না)
2. Node.js ইনস্টল করা কম্পিউটার বা সার্ভার

## নিজের কম্পিউটারে চালানো
```bash
npm install
cp .env.example .env
# .env ফাইল খুলে GEMINI_API_KEY= এর পরে নিজের key বসান
npm start
```
তারপর ব্রাউজারে খুলুন: http://localhost:3000

## ফ্রি সীমা কতটুকু?
Gemini 2.5 Flash মডেলে দিনে প্রায় ৫০০টা পর্যন্ত রিকোয়েস্ট ফ্রি — সাধারণ ব্যক্তিগত ব্যবহারের জন্য যথেষ্ট। সীমা মাঝেমধ্যে পাল্টাতে পারে, তাই চালানোর আগে aistudio.google.com-এ গিয়ে current free tier limit দেখে নেওয়া ভালো।

## ইন্টারনেটে সবসময় চালু রাখতে (হোস্টিং)
নিচের যেকোনো একটা ফ্রি/সস্তা সার্ভিসে ডিপ্লয় করতে পারবেন:
- **Render.com** — সবচেয়ে সহজ, ফ্রি টিয়ার আছে
- **Railway.app**
- **Vercel** (তবে এই কোডটা Express সার্ভার, তাই Render/Railway বেশি সহজ হবে)

সব জায়গাতেই একই কাজ:
1. এই ফোল্ডার GitHub-এ আপলোড করুন
2. Render/Railway-তে "New Web Service" বানিয়ে GitHub রিপো কানেক্ট করুন
3. Environment Variables-এ `GEMINI_API_KEY` যোগ করুন (আপনার আসল key দিয়ে)
4. Deploy করুন — একটা পাবলিক লিংক পাবেন, যেটা যেকেউ ভিজিট করতে পারবে

## গুরুত্বপূর্ণ
- `.env` ফাইল কখনো GitHub-এ পাবলিশ করবেন না (এতে আপনার সিক্রেট key থাকে) — `.gitignore`-এ `.env` যোগ করে নিন
- ফ্রি সীমার বেশি ব্যবহার হলে সাময়িকভাবে রিকোয়েস্ট আটকে যেতে পারে, পরদিন আবার রিসেট হয়ে যায়
